# Learn Digital Twins with Phoebe

Sixteen 45-minute sessions on digital twins as a data problem, by Phoebe Fu. Two tracks: six leader
sessions (no code) and ten practitioner sessions, ending in a twin sync bench that runs in the browser.

The running case, Kittiwake Hall, is a constructed six-storey teaching building. Every Kittiwake number
is generated by the seeded engine in `assets/dtw-live.js` and checked by a Python reference in
`materials/`. Research and standards are cited on each page. Not investment advice.

Open `index.html` to start.
